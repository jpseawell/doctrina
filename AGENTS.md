# Learning sessions

Keep this repository simple and use it to record Justin's technical learning exercises.

- Create a descriptive topic/lesson directory, such as `systems-architecture/url-shortener/`, with a concise `README.md`.
- Record the topic, problem and constraints, then attempts in chronological order. For each, describe what Justin actually did, give a 1–5 score with a brief rationale, and summarize actionable feedback. Re-evaluate revisions on their own merits and note when they follow coaching.
- Preserve available diagrams or screenshots beside the lesson and link them with relative paths. Label what each image shows; don't reconstruct missing attempts as if they were originals.
- Finish with a short educator's summary beginning “Justin has demonstrated…” that distinguishes observed skills from topics merely explained or still uncertain. Include the date and the actual evaluator model at the bottom.
- Add each lesson to the root README below the horizontal rule in reverse chronological order. Avoid duplicate entries when updating a lesson.
- Do not claim a skill is mastered or an attempt exists without evidence. Ask for clarification when an assessment cannot be made from the available work.
